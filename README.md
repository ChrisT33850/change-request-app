# Change Request Dashboard 📋

Une web app **React** pour gérer les Change Requests avec **signatures digitales en temps réel** et **historique complet**.

## 🎯 Caractéristiques

✅ **Authentification simple** (login/password)  
✅ **Dashboard temps réel** avec filtrage par statut  
✅ **Signatures digitales** (nom + timestamp)  
✅ **Historique complet** (audit trail)  
✅ **Synchronisation GitHub** (données stockées dans le repo)  
✅ **Déploiement gratuit** sur GitHub Pages
